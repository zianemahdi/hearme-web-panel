HearMe — Politique de confidentialité

Dernière mise à jour : 13 août 2026

HearMe est une application de sécurité personnelle (anti-vol / localisation de votre propre téléphone). Cette politique explique quelles données sont utilisées, par l'application Android et par le panneau web d'urgence optionnel.

En bref. Le traitement se fait d'abord sur l'appareil. Le micro et les photos ne quittent pas le téléphone, sauf les alertes que vous configurez. Le panneau web et la synchronisation cloud sont optionnels : ils ne s'activent que si vous créez un compte ou utilisez une clé secrète pour piloter votre téléphone à distance.

1. Données utilisées par l'application

Micro (mot-clé vocal)

La reconnaissance du mot-clé se fait sur l'appareil. Aucun audio n'est enregistré ni transmis.

Localisation

Utilisée pour l'anti-vol (joindre la position à vos alertes) et pour afficher la carte. La localisation en arrière-plan n'est utilisée que si vous activez la carte communautaire.

Caméra

En cas de vol ou d'échec de déverrouillage (anti-vol armé), une photo de la caméra frontale peut être envoyée à votre canal Telegram et, si vous utilisez le panneau web, à votre espace de stockage privé (voir §2).

Signalement communautaire (optionnel, désactivé par défaut)

Si vous l'activez, un vol confirmé peut alimenter la carte des zones à risque via un signalement anonyme : coordonnées bruitées (±150 m), horodatage arrondi, aucun identifiant ni adresse IP conservés.

2. Panneau web & synchronisation cloud (optionnel)

Le panneau web vous permet de localiser et sécuriser votre téléphone depuis un navigateur. Il repose sur Supabase (hébergement des données). Cette synchronisation ne s'active que si vous l'utilisez (compte ou clé secrète). Sont alors stockées, pour votre appareil :

  • Positions GPS (dernière position et historique récent) ;
  • État de l'appareil : niveau de batterie, type de réseau, statut de verrouillage, dernière activité ;
  • Photos de sécurité (caméra frontale) dans un espace de stockage privé ;
  • Commandes à distance que vous déclenchez (verrouiller, alarme, localiser…) ;
  • Si vous créez un compte : votre adresse e-mail (authentification) ;
  • La clé secrète de l'appareil, qui sert d'identifiant/mot de passe de commande.

Ces données ne sont accessibles qu'à vous : soit via votre compte (isolation par « Row Level Security »), soit via la clé secrète de l'appareil. Elles ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires. Communications en HTTPS/TLS.

3. Partage

Nous ne vendons ni ne partageons vos données avec des tiers à des fins publicitaires. Les seules sorties de données sont celles que vous déclenchez et dirigez vous-même (alertes vers votre Telegram, votre propre panneau web) et le signalement anonyme si vous y avez consenti. Le sous-traitant technique d'hébergement est Supabase (base de données et stockage).

4. Conservation et suppression

  • Les réglages et secrets locaux (code, token) restent chiffrés sur l'appareil et sont supprimés à la désinstallation.
  • Les données du panneau web (positions, photos, état) sont conservées dans votre espace jusqu'à leur suppression. Vous pouvez demander leur effacement (voir Contact) ; supprimer un appareil supprime en cascade ses positions, photos et commandes.
  • Les signalements communautaires anonymes ne contiennent aucun identifiant et décroissent avec le temps.

Chaque permission est demandée au moment de l'usage, révocable dans les réglages Android ; l'app reste fonctionnelle (mode dégradé) si elle est refusée.

6. Sécurité

  • Secrets locaux chiffrés via EncryptedSharedPreferences (clé dans le KeyStore Android).
  • Côté cloud : Row Level Security (chaque compte ne voit que ses appareils), stockage des photos privé (URLs signées, temporaires), accès par clé secrète via des fonctions serveur restreintes.
  • Toutes les communications réseau en HTTPS/TLS.

7. Conformité réglementaire

RGPD / GDPR (Union européenne)

Base légale : consentement (usage du panneau web, carte communautaire) et intérêt légitime (sécurité de l'utilisateur). Minimisation : seules les données nécessaires à la localisation/sécurisation de votre appareil sont traitées. Droits d'accès, rectification et effacement assurés (données locales supprimées à la désinstallation ; données cloud effaçables sur demande).

CCPA / CPRA (Californie)

Pas de « vente » ni de « partage » de données personnelles. Droits « Know / Delete / Opt-out » respectés ; le panneau web est désactivable à tout moment.

LGPD (Brésil)

Finalité et nécessité limitées à la sécurité ; consentement libre et éclairé ; anonymisation des signalements communautaires.

8. Vos choix

  • Le panneau web et la synchronisation cloud sont optionnels et cessent si vous ne les utilisez pas.
  • La contribution à la carte communautaire est opt-in, désactivable à tout moment.
  • Les permissions (micro, localisation, caméra) sont révocables dans les réglages Android.
